## درباره‌ی پروژه

انتخاب واحد یار به دانشجویان کمک می‌کند ارائه‌های دروس را به یک برنامه‌ی هفتگی کاربردی تبدیل کنند. جستجوی درس، مقایسه‌ی گروه‌ها، برنامه‌ریزی محلی، پیگیری پیشرفت درسی و شناسایی تداخل‌ها در یک رابط کاربری فارسی‌محور کنار هم قرار گرفته‌اند.

کلاینت اصلی یک برنامه‌ی استاتیک و بدون مرحله‌ی build است. می‌توان آن را با یک سرور HTTP ساده به‌صورت محلی اجرا کرد یا به‌عنوان سایت استاتیک روی GitHub Pages منتشر کرد. یک سرویس اختیاری FastAPI نیز برای دستیار هوش مصنوعی وجود دارد که کلیدهای سرویس‌دهنده را در مرورگر قرار نمی‌دهد.

### قابلیت‌ها

- جستجوی درس با نام درس، استاد یا کد درس.
- فیلتر بر اساس دانشکده، گروه آموزشی، روز، تعداد واحد، ظرفیت، جنسیت، داشتن ظرفیت و تداخل با برنامه.
- مستقل بودن رشته‌ی پروفایل از فیلترهای موقت جستجو.
- مقایسه‌ی گروه‌های یک درس با نمایش زمان، استاد، ظرفیت، امتحان و مکان.
- ساخت برنامه‌ی هفتگی و جابه‌جایی بین نماهای هفتگی، فهرست و امتحان‌ها.
- شناسایی تداخل زمانی کلاس، امتحان، استاد، درس تکراری و سقف واحد.
- پیگیری دروس گذرانده و پیش‌نیازها بر اساس رشته‌ی انتخاب‌شده در پروفایل.
- خروجی تقویم در قالب iCalendar و چاپ برنامه.
- راهنمای تعاملی ورود اول و دستیار اختیاری برنامه‌ریزی تحصیلی مبتنی بر هوش مصنوعی.
- ذخیره‌ی پروفایل و برنامه در مرورگر بدون نیاز به ساخت حساب کاربری.

### فناوری‌های استفاده‌شده

- HTML، CSS و JavaScript بومی مرورگر
- [Vazirmatn](https://github.com/rastikerdar/vazirmatn) برای رابط فارسی
- [FastAPI](https://fastapi.tiangolo.com/) برای سرویس اختیاری هوش مصنوعی
- تست داخلی [Node.js](https://nodejs.org/) و [Playwright](https://playwright.dev/) برای تست مرورگر
- [Python](https://www.python.org/)، [uv](https://docs.astral.sh/uv/) و [Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/) برای ابزارهای داده
- GitHub Actions و GitHub Pages برای CI و انتشار استاتیک

## شروع کار

### پیش‌نیازها

- Python نسخه‌ی ۳.۱۲ یا جدیدتر
- Node.js نسخه‌ی ۲۲ یا جدیدتر برای بررسی‌های توسعه و تست مرورگر
- `uv` برای وابستگی‌های Python، pipeline داده و API اختیاری
- یک مرورگر به‌روز

کلاینت وب به‌تنهایی مرحله‌ی build یا API لازم ندارد.

### نصب و اجرا

۱. مخزن را clone کنید:

```bash
git clone https://github.com/VRUCS/course-planner.git
cd course-planner
```

۲. وابستگی‌های توسعه را نصب کنید:

```bash
npm ci
uv sync --locked
```

۳. کلاینت استاتیک را اجرا کنید:

```bash
python3 -m http.server 3000 --directory apps/web
```

۴. آدرس <http://127.0.0.1:3000> را در مرورگر باز کنید.

برای ساخت artifact عمومی ابتدا این دستورها را اجرا کنید:

```bash
uv run python tools/build_static.py
python3 -m http.server 3000 --directory _site
```

در این build، ویرایشگر محلی داده، داده‌های منبع و فایل‌های backend عمداً وارد artifact عمومی نمی‌شوند.

### سرویس هوش مصنوعی اختیاری

دستیار هوش مصنوعی به‌صورت پیش‌فرض غیرفعال است. برای اجرای محلی آن:

۱. فایل تنظیمات نمونه را کپی کنید:

```bash
cp apps/api/.env.example apps/api/.env
```

۲. مقدار `OPENROUTER_API_KEY` را تنظیم کنید. مقدار `AI_INTERACTIVE_ENABLED=false` را نگه دارید، مگر این‌که آگاهانه بخواهید سرویس را فعال کنید. origin کلاینت را نیز تنظیم کنید.

۳. API را اجرا کنید:

```bash
uv run uvicorn apps.api.main:app --reload --host 127.0.0.1 --port 8000
```

کلید `OPENROUTER_API_KEY` یا هر secret دیگری را در کلاینت وب یا مخزن عمومی قرار ندهید.

## نحوه‌ی استفاده

۱. دانشکده، گروه آموزشی، ورودی و در صورت نیاز معدل را در پروفایل تحصیلی وارد کنید.
۲. یک درس را جستجو کنید یا از فیلترهای دانشکده و گروه آموزشی استفاده کنید.
۳. گروه‌های درس را بررسی و گروه مناسب را به برنامه اضافه کنید.
۴. نتیجه را در نماهای هفتگی، فهرست و امتحان‌ها بررسی کنید.
۵. هشدارهای برنامه را پیش از نهایی کردن برطرف کنید.
۶. پس از آماده شدن برنامه، از چاپ یا خروجی تقویم استفاده کنید.
۷. برای بررسی دروس گذرانده و پیش‌نیازها وارد تب نقشه‌ی درسی شوید.

رشته‌ی پروفایل، مبنای نمایش نقشه‌ی درسی است. فیلترهای جستجو مستقل هستند؛ بنابراین دانشجو می‌تواند موقتاً دنبال درسی از یک گروه دیگر بگردد، بدون این‌که رشته‌ی پروفایل تغییر کند.

## داده و حریم خصوصی

- برنامه‌ی استاتیک به ورود کاربر یا database نیاز ندارد.
- پروفایل، برنامه، پیشرفت درسی و تنظیمات در local storage مرورگر ذخیره می‌شوند.
- سرویس اختیاری هوش مصنوعی یک مرز backend جدا دارد و کلید سرویس‌دهنده فقط توسط سرور خوانده می‌شود.
- پیش از تصمیم‌گیری برای انتخاب واحد، اطلاعات دروس و نقشه‌ی درسی را با منابع رسمی دانشگاه تطبیق دهید.

## ساختار پروژه

```text
apps/web/          کلاینت استاتیک دانشجو و استاد
apps/api/          سرویس اختیاری FastAPI برای هوش مصنوعی
apps/extension/    افزونه‌ی مرورگر برای استخراج اطلاعات دروس
data/canonical/    داده‌ی نرمال‌شده‌ی دروس، نقشه‌ی درسی و قوانین تداخل
data/sources/      فایل‌های منبع pipeline داده
tools/             ابزار build استاتیک و pipeline داده
tests/             تست‌های backend، frontend، pipeline و end-to-end
docs/assets/       اسکرین‌شات‌ها و دارایی‌های مستندات
```

کلاینت مرورگر به بخش‌های منطق دامنه، adapterها، قابلیت‌های مشترک، کنترلرهای صفحه، wrapperهای داده‌ی تولیدشده و styleها تقسیم شده است. برای جزئیات فنی بیشتر به READMEهای [`apps/web`](apps/web/README.md)، [`apps/api`](apps/api/README.md)، [`data`](data/README.md) و [`tools/data_pipeline`](tools/data_pipeline/README.md) مراجعه کنید.

## تست

تست‌های واحد JavaScript و lint:

```bash
npm test
npm run lint
```

تست مرورگر:

```bash
npm run test:e2e
```

تست‌ها و بررسی‌های Python:

```bash
uv run python -m pytest -q
uv run ruff check .
```

workflow کامل CI داده‌های تولیدشده، syntax جاوااسکریپت، artifact عمومی و مرزهای انتشار را نیز بررسی می‌کند.
