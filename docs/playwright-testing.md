# تست مرورگری با Playwright

این پروژه علاوه بر تست‌های واحد، یک مجموعه تست سرتاسری Chromium دارد. Playwright
سایت استاتیک را با یک وب‌سرور محلی مستقل اجرا می‌کند و هر تست را در context تازه و
بدون دادهٔ ذخیره‌شده آغاز می‌کند.

## اجرا

```bash
npm install
npx playwright install chromium
npm run test:e2e
```

برای عیب‌یابی تعاملی:

```bash
npm run test:e2e:headed
npm run test:e2e:ui
npm run test:e2e:report
```

تنظیمات در `playwright.config.js` است. سرور، محتوای `apps/web` را روی پورت ثابت
`4173` ارائه می‌کند. در CI دو worker، دو بار retry، گزارش HTML و line فعال است.
در شکست تست، screenshot، trace و video در `test-results` نگه‌داری می‌شوند.

## پوشش سناریوها

- بارگذاری اولیه، راست‌به‌چپ بودن صفحه، فهرست درس‌ها و برنامهٔ خالی
- جستجوی درس و باز و بسته‌شدن فیلترهای پیشرفته
- افزودن یک درس تک‌گروهی و ظاهرشدن آن در جدول هفتگی
- ماندگاری انتخاب پس از reload مرورگر
- ذخیرهٔ پروفایل تحصیلی، اعمال رشته و معدل، نمایش درس‌های مرتبط و ماندگاری پس از reload
- باز و بسته‌شدن پنجرهٔ «درباره»
- بازکردن جریان تقویم، ورود بازهٔ ترم و لغو امن بدون دانلود یا ناوبری خارجی
- ناوبری پایین صفحه در اندازهٔ موبایل
- سند چاپی، نمایش درس، حذف رابط اصلی و پس‌زمینهٔ سفید کم‌مصرف

تست‌ها تا جای ممکن از role، label و متن قابل مشاهده استفاده می‌کنند. درس
تک‌گروهی مورد نیاز در زمان اجرا از دادهٔ فعلی پیدا می‌شود و نام یا شناسهٔ ثابتی
در تست hard-code نشده است.

## مرزهای فعلی

پروژهٔ پیش‌فرض فقط Chromium است تا اجرای روزمره سریع و قطعی بماند. پوشش
Firefox، WebKit/Safari، چاپ فیزیکی، صفحه‌خوان‌ها و دستگاه‌های واقعی هنوز نیازمند
اعتبارسنجی جداگانه است. تست چاپ ساختار و CSS محاسبه‌شده را بررسی می‌کند، نه خروجی
نهایی درایور چاپگر. جریان تقویم نیز فایل ICS را بررسی می‌کند و عمداً وارد حساب
واقعی Google نمی‌شود.

## نتیجهٔ آخرین اجرا

پس از اضافه‌شدن مجموعهٔ E2E بدون خطا اجرا شدند.
