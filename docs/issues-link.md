# پیوند گزارش مشکل و پیشنهاد

در پنجرهٔ «درباره» یک اقدام مستقل برای «گزارش خطا یا پیشنهاد» اضافه شد که کاربر
را مستقیماً به صفحهٔ Issues مخزن پروژه می‌برد. متن کوتاه کنار آن روشن می‌کند
که خطاها و پیشنهادهای بهبود را می‌توان در آن صفحه مطرح کرد.

پیوند در زبانهٔ تازه باز می‌شود و برای جلوگیری از دسترسی صفحهٔ مقصد به پنجرهٔ
برنامه، ویژگی‌های `noopener noreferrer` دارد. حالت فوکوس صفحه‌کلید نیز به‌صورت
واضح نمایش داده می‌شود.

## بررسی

- `npm test`
- `npm run lint`
- `git diff --check`
