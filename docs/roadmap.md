هر فاز باید با تست و commit جدا بسته شود.

## فاز ۱ — تعمیم مدل داده

و کلید آن‌ها رشته دقیق فارسی «دانشکده >> گروه» است. برای بیش از یک رشته مقیاس‌پذیر نیست.

- [ ] انتقال چارت درسی و قوانین تداخل به JSON در `assets/data/` با schema مشخص
- [ ] اعتبارسنجی schema در convert/CI (کد درس‌ها باید در `courses.json` موجود باشند)
- [ ] registry رشته‌ها به‌جای کلید رشته‌ای متنی، برای افزودن رشته دوم بدون تغییر کد
- [ ] تولید قوانین تداخل از خود چارت (ترم مشابه/هم‌تراز) به‌صورت deterministic؛
      خروجی AI فقط به‌عنوان پیش‌نویسِ قابل بازبینی

- [ ] تشخیص تداخل امتحان بر اساس تاریخ **و ساعت** (اکنون فقط شمارش هم‌تاریخ)
